# 反制盾一键对讲 Demo

这是一个纯前端交互 Demo，不改动现有反制盾原型。

## 运行

推荐在本目录运行本地 Web 服务，以便浏览器正常申请麦克风权限：

```powershell
python -m http.server 8090
```

然后访问 `http://localhost:8090`。

也可以直接双击 `index.html` 查看全部界面和模拟交互，但部分浏览器在 `file://` 页面下不会开放麦克风。

## 已包含

- 设备首页“对讲”快捷入口
- 通讯录、在线状态和单人选择
- 对讲小组列表、成员展示、创建小组
- 鼠标/触屏按住说话，或按住空格键发话
- 浏览器麦克风录音和本地回放；无权限时自动使用模拟消息

> 当前版本仅用于产品交互演示，没有连接真实账号、服务器或实时语音网络。
